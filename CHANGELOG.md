# Changelog

## 0.1.0 — 2026-09-29

First public release.

- Button bar docked to the right edge of the Claude desktop window: collapsible tab, `Ctrl+Alt+B`, follows the window, hides with it, matches Claude's light/dark theme, per-monitor DPI aware.
- MCP server with `add_button`, `list_buttons`, `get_button`, `update_button`, `remove_button` and `run_button`; works with `mcp` 1.x and 2.x.
- PowerShell, Python and batch scripts; last-run status and output for every button.
- `dock_to` setting to dock to other apps (Windows Terminal, VS Code, ...).
- `install.ps1` / `uninstall.ps1`.
